# Resources

| Folder | What it holds |
|---|---|
| [datasets/](datasets/) | Dataset catalogue, one card per dataset, raw downloads (gitignored), processed and synthetic data |
| [libraries/](libraries/) | Registry of libraries and models we evaluated, adopted or rejected, with reasons |

Raw data is downloaded with `scripts/fetch-data`. Model weights are downloaded with `scripts/fetch-models` (see [models/](../models/)).
