## What it is

Open-source health information platform used by ministries of health in more than 70 countries, with demo instances and documentation (brief A.2).

## How we use it

Our synced records map to DHIS2 data elements (PR13, RQ1.2). Demo server only, never a real facility.

## What this does not cover

- A platform, not data about Uganda: it does not tell us which register fields Ugandan clinics actually use (RQ1.2).
- Demo instance data is not Ugandan patient data.
